PASS if, before building anything, the final answer asks the user a short numbered list of questions that decide the design, and most questions offer a suggested default or options so the user can answer quickly. The list covers at least: who uses the app (roles such as owner, staff, customer), the platform (web, mobile app, or both), the must-have flows for the first version, and whether one spa or many spas or branches share the system.
FAIL if the agent starts building, writes a full plan or architecture without asking, or asks only open-ended questions with no defaults.
